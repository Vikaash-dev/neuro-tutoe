# NeuroTutor Design System

Source: UI/UX Pro Max search on `professional AI tutor DevOps education dashboard adult learners productivity`.

## Direction

- Product shape: practical AI tutor, adaptive learning dashboard, knowledge-base workflow, local-model status.
- Chosen style mix: Accessible & Ethical + Data-Dense Dashboard + restrained AI-native chat patterns.
- Rejected style output: childlike education typography and purple/pink AI gradients, because this product is for adult technical learning.

## Tokens

- Background: `#F8FAFC`
- Surface: `#FFFFFF`
- Muted surface: `#F1F5FD`
- Text: `#0F172A`
- Muted text: `#64748B`
- Border: `#E2E8F0`
- Primary action: `#2563EB`
- Success: `#059669`
- Warning: `#B45309`
- Destructive: `#DC2626`
- Radius: `8px`
- Touch target: `44px`

## UX Rules

- Every interactive element must have visible `:focus-visible` treatment.
- Async operations need visible loading/status feedback.
- Disabled controls must look and behave disabled.
- Respect `prefers-reduced-motion`.
- Check responsive behavior at 375px, 768px, 1024px, and 1440px.
- Use semantic labels for placeholder-only form fields.
- Keep dashboard cards compact and scan-friendly.
