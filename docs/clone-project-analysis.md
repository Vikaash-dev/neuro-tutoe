## Whole-System Verdict

The current app is a correct practical baseline because it takes the most repeated high-value patterns across the clones and implements them in one runnable web tutor:

- Feynman teach-back and misconception repair from `neuro-tutoe`.
- Configurable tutor behavior from `mr-ranedeer`.
- Learner model / theory-of-mind style adaptation from `tutor-gpt`.
- Goal-oriented learning paths from `gen-mentor`.
- Socratic question mode and prerequisite tracking from `mathvoice` / `ostep-socratic-tutor`.
- Whiteboard/artifact direction from `ChatTutor` and `mathvoice`.
- Multi-role study assistant flow from `multi-agent-study-assistant`.
- Smart resume / lesson-script direction from `tov-learn`.
- Document/course generation direction from `learnflow-ai`.
- Knowledge-base, hybrid retrieval, citation, and notebook direction from `DeepTutor`.
- Per-response tutor self-evaluation, now surfaced in live chat and saved into
  the learner journal as a practical quality gate.
- Citation notebook, now surfaced in Progress and built from the durable learner
  journal so source usage can be audited across tutor, teach-back, and quiz events.
- Course outlines, now generated from the current concept graph, learner model,
  goal, and KB source coverage as a bridge from one-off sessions to courses.

## What Was Deliberately Not Copied

- Full mobile Expo stack from `neuro-tutoe`.
- Hosted SaaS/auth/payment/analytics stacks from `tutor-gpt`, `learnflow-ai`, and `llamatutor`.
- Heavy multi-agent frameworks before the single tutor loop is proven.
- Web search, paper search, code execution, and exam mimic flows until safety/eval scaffolding is stronger.
- AGPL code from projects where direct copying could force licensing obligations.
